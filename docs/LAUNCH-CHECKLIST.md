# Launch Checklist

## Content and brand

- [ ] Placeholder business names, email addresses and copy are removed.
- [ ] Logo, favicon, colors and imagery are approved.
- [ ] Every page has a unique title, description and first heading.
- [ ] Phone numbers, email addresses, prices and calls to action are correct.
- [ ] Legal and privacy pages match the project's real practices.

## Functionality

- [ ] Navigation works on desktop, keyboard and mobile.
- [ ] Forms deliver to the intended destination and show success and failure states.
- [ ] All links, downloads and buttons work.
- [ ] Empty, loading and error states are understandable.
- [ ] Authentication and password recovery work when enabled.

## Security and data

- [ ] No production secrets appear in source files.
- [ ] RLS is enabled and tested when Supabase is used.
- [ ] Administrative authorization is enforced beyond the interface.
- [ ] Public forms have server validation and abuse protection.
- [ ] Backups and recovery procedures exist for durable data.

## Accessibility

- [ ] All controls have accessible names.
- [ ] Forms use labels and useful error messages.
- [ ] Keyboard focus is visible.
- [ ] Text remains usable at 200% zoom.
- [ ] Color contrast works in both themes.
- [ ] Reduced-motion preferences are respected.

## Performance and quality

- [ ] Images are appropriately sized and optimized.
- [ ] Unused scripts and styles are removed from the project copy.
- [ ] Mobile pages do not scroll horizontally.
- [ ] Browser console is clear of unexpected errors.
- [ ] `npm run verify` passes.
