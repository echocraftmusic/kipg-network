# Changelog

## 2.0.0 — September 2026

- Reorganized the framework around core, templates, modules, integrations, and assets.
- Added Cherry Executive and Black Onyx semantic theme tokens.
- Added persistent theme selection with accessible toggle support.
- Added reusable navigation, modal, notification, form, storage, and repository utilities.
- Added a generic administration starter based on the newer Echo Craft dashboard work.
- Added optional Supabase authentication and administrator-guard adapters.
- Added a privacy-conscious analytics adapter.
- Added JSON-based site configuration and content loading.
- Added security, accessibility, performance, and launch checklists.
- Removed live Echo Craft Studio credentials, customer data, and project-specific content.
- Separated specialized referral SaaS database logic from the general website framework.
